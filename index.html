Mac Mini Backup

A personal utility for copying selected local backup archives from the owner's Mac mini to the owner's Google Drive using rclone.

How it works

The owner selects files locally and authorizes rclone through Google OAuth. The utility uploads backup archives to a designated Google Drive folder and can list, download, or remove its backup files as directed by the owner.

Private files stay private

This website provides app information only. It does not receive backup files, OAuth credentials, or Google account data. It has no login form and is not a public backup service.

The intended Google Drive permission is drive.file, which limits the utility to files it creates or files explicitly authorized for it.
